# Security

Heart words has no server account. A parent name, a student name, and a PIN stay in the browser or the installed app on that device. Clearing the site data deletes them.

The PIN only unlocks settings on that device. It is not an online password.

## Reporting a vulnerability

Use GitHub Security advisories on [elephantatech/heart-words](https://github.com/elephantatech/heart-words/security/advisories) so the report stays private.

Include what you did, what you expected, and the smallest page or file that shows the problem. Leave out a child's name, a parent's name, and any PIN.

A public issue is fine for a mistake that does not expose someone else's information.
