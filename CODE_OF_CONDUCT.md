# Code of conduct

Heart words is a practice page for children. Conversation in issues and pull requests stays useful for that work.

## Expected behavior

- Talk about the lesson, the page, and the change.
- Disagree about the work in plain words.
- Assume other people are here to help a child practice.

## Unacceptable behavior

- Insults, harassment, or sexual comments.
- Posting a child's name, a parent's name, a PIN, or another person's private information.
- Spam, advertisements, or requests to turn the page into a paid product inside this repository.

## Reporting

Open a GitHub issue for a public problem. For a private report, use Security advisories on this repository, as described in `SECURITY.md`.

Elephantatech reviews reports and may edit or hide a comment, or block further participation, when a comment breaks these rules.
